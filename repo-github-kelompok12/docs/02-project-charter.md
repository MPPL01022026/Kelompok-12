## 2. Ruang Lingkup

**Termasuk (usulan):**
- Pencatatan pesanan untuk empat produk.
- Pencatatan stok dan penjualan harian.
- Ringkasan penjualan sederhana untuk Kak Linda.
- Website pemesanan sebagai salah satu jalur masuk pesanan.

**Tidak termasuk (usulan):**
- Pembayaran online dan pengiriman.
- Produk di luar empat produk saat ini.
- Aplikasi seluler terpisah.
- Pencatatan keuangan lengkap (akuntansi). [KONFIRMASI Kak Linda]
