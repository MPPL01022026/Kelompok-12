# Pengembangan Digital Twin UMKM Bakso Goreng Kak Linda

## Monitoring Penjualan dan Stok (WarungTwin)

**Kelompok 12**

Repositori ini berisi dokumentasi dan hasil pengerjaan proyek pengembangan Digital Twin UMKM pada Bakso Goreng Kak Linda untuk mendukung monitoring penjualan dan stok.

---

## Tujuan Proyek

Proyek ini bertujuan untuk mengembangkan konsep Digital Twin yang dapat membantu proses monitoring aktivitas warung secara lebih terstruktur, khususnya pada aspek penjualan dan stok. Sistem yang dirancang mencakup pencatatan penjualan digital, dashboard stok real-time, simulasi permintaan, prediksi kebutuhan stok harian, dan laporan pendapatan otomatis.
